CROCODILES WARS — КРОССПЛАТФОРМЕННЫЙ ОНЛАЙН

Поддерживаемые комбинации:
- ПК с телефоном
- телефон с ПК
- телефон с телефоном
- ПК с ПК

Важно: все игроки открывают один и тот же HTML-файл (или его опубликованную веб-версию) и вводят одинаковый адрес WebSocket-сервера.

Локальная проверка на ПК:
1. Установи Node.js LTS: https://nodejs.org/
2. Открой терминал в папке с файлами сервера.
3. Выполни: npm install
4. Запусти: npm start
5. На компьютере в адрес сервера введи ws://localhost:3000

ПК + телефон в одной Wi-Fi сети:
1. Запусти сервер на ПК.
2. Узнай IPv4 компьютера командой ipconfig.
3. На обоих устройствах укажи ws://IP-АДРЕС-ПК:3000 (например, ws://192.168.1.20:3000).
4. Разреши Node.js доступ через брандмауэр Windows для частной сети.

Игроки через интернет / разные сети:
1. Размести server.js на хостинге, поддерживающем Node.js и WebSocket.
2. Используй публичный защищённый адрес wss://...
3. Оба игрока вводят один и тот же wss:// адрес и код комнаты.

Ограничения текущей сетевой версии:
Сервер передаёт позиции и повороты игроков и поддерживает комнаты. Боевая логика, здоровье, попадания и полная синхронизация состояния ещё не реализованы на серверной стороне. Это прототип, не полноценный соревновательный онлайн.
